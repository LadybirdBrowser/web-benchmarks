About StyleBenchConservative

StyleBenchConservative runs the same style resolution and style invalidation workload as StyleBench. Before and after each mutation, it reads the body's computed backgroundColor and bounding rectangle to explicitly flush both style and layout.

StyleBench uses the Speedometer framework for UI and measurements.

Access via 'file:' protocol

To run locally, launch a web server under the benchmarks directory and access StyleBenchConservative through that server.

Individual tests (without measurement) can also be run from resources/style-bench.html.
